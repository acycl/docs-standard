# Acycl documentation standard

How Acycl projects write documentation: plain Markdown in each project's
repository that reads well on GitHub and that acycl.dev renders unchanged.

- [Adopting the standard](adopting.md) — set up a project's `docs/`
  directory, its checks, and its place on the site
- [The standard](standard.md) — the layout and syntax every page follows,
  and what each construct becomes on the site
